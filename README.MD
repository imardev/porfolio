# Portfolio Personal

Portfolio personal desarrollado para mostrar mis proyectos, conocimientos y evolución como estudiante de desarrollo de software.

El proyecto combina un frontend desarrollado con tecnologías web estándar con un backend propio encargado de gestionar dinámicamente la información del portfolio.

---

## 🚀 Objetivo

El objetivo del portfolio es:

- Mostrar mis proyectos de forma clara y organizada.
- Presentar las tecnologías y conocimientos adquiridos.
- Servir como carta de presentación profesional.
- Aplicar en un proyecto real los conocimientos de frontend, backend, APIs y bases de datos.

## 🏗️ Arquitectura

El proyecto está dividido en frontend, backend y base de datos.

```text
Portfolio
│
├── Frontend
│   ├── HTML5
│   ├── CSS3
│   ├── JavaScript
│   └── Bootstrap
│
├── Backend
│   ├── Node.js
│   ├── Express
│   ├── Prisma
│   └── API REST
│
└── Database
    └── PostgreSQL
        └── Neon
```

El frontend consume la API del backend para obtener información sobre los proyectos y las tecnologías asociadas.

El backend utiliza Prisma para comunicarse con PostgreSQL y gestionar los datos almacenados en la base de datos.
